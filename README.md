# MODUL. — сайт-каталог современной мебели

Демонстрационный многостраничный сайт для портфолио. Проект показывает, как можно представить мебельную коллекцию через каталог, подробные страницы моделей, материалы и интерьерные фотографии.

Визуальный стиль построен на нейтральной палитре, крупной типографике, свободном пространстве и внимании к пропорциям предметов.

MODUL. — вымышленный бренд, а не действующий интернет-магазин или реальный производитель мебели. Модели, размеры и описания используются для демонстрации.

## Возможности сайта

- Адаптивная главная страница с категориями, избранными моделями и материалами.
- Каталог из 15 демонстрационных моделей с совместной фильтрацией по категории и направлению отделки, счётчиком результатов и сбросом фильтров.
- Подробные страницы четырёх представленных моделей: LINEA 01 — комод, TERRA 02 — шкаф, FRAME 03 — стеллаж, NODO 04 — тумба.
- Разделы о подходе к созданию мебели и четырёх визуальных направлениях материалов.
- Мобильное меню и навигация между разделами.
- Демонстрационная форма обращения с выбором активной модели, её предвыбором при переходе со страницы товара и проверкой обязательных полей.

Остальные 11 моделей обозначены как «Скоро в коллекции». Их карточки участвуют в фильтрации, но не содержат ссылок на страницы товаров и не доступны для выбора в форме.

**Форма не отправляет и не сохраняет данные.** Она демонстрирует взаимодействие с пользователем и сообщения о результатах проверки полей. Направления отделки не подтверждают доступность реальных вариантов исполнения.

## Структура проекта

| Раздел | Файл | Содержание |
|---|---|---|
| Главная | `index.html` | Коллекция, категории, избранные модели и знакомство с брендом |
| Каталог | `catalog.html` | Карточки моделей и фильтры |
| Производство | `production.html` | Концептуальный подход к функции, пропорциям и деталям мебели |
| Материалы | `materials.html` | Светлый дуб, тёплый орех, мягкий greige и глубокий графит |
| Контакты | `contact.html` | Демонстрационная форма обращения |
| Модели | `products/` | Четыре активные страницы и сохранённые заготовки будущих моделей |

Стили находятся в `css/`, сценарии — в `js/`. Каталог `assets/` содержит иконку, оптимизированные изображения WebP и сохранённые PNG-оригиналы.

## Технологии

- **HTML5** — структура и содержание страниц.
- **CSS3** — оформление, сетки и адаптивная компоновка.
- **Vanilla JavaScript** — фильтрация каталога, мобильное меню и валидация формы.
- **GitHub Pages** — публикация статического сайта.

Проект не требует сборки, установки зависимостей или серверной части.

## Адаптивность

Сайт рассчитан на компьютеры, планшеты и смартфоны. Компоновка проверена на ширинах 1920, 1440, 1024, 768, 390 и 360 px.

Для изображений используются адаптивные размеры. Предметные кадры сохраняют полный силуэт мебели; детали и интерьерные композиции кадрируются с учётом назначения блока.

## Локальный запуск

Скачайте ZIP через **Code → Download ZIP** на [странице репозитория](https://github.com/RobDiezz/modul-demo) и распакуйте его. Либо клонируйте проект:

```sh
git clone https://github.com/RobDiezz/modul-demo.git
cd modul-demo
```

Откройте `index.html` в браузере. Установка зависимостей не нужна: навигация, фильтры, мобильное меню и демо-форма работают при локальном открытии файлов. Для просмотра можно также использовать любой локальный статический HTTP-сервер, но он не является обязательным.

## Статус проекта

Проект завершён и опубликован на GitHub Pages как демонстрационная работа для портфолио. Сайт показывает визуальное оформление и пользовательские сценарии каталога; он не принимает заказы и не представляет реального производителя мебели.
